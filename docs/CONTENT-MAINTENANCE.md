# Manutenção de conteúdo

## Quando revisar um artigo

Revise imediatamente quando uma fonte oficial mudar, uma ferramenta for descontinuada, uma interface citada no texto mudar, um dado perder contexto ou uma página de serviço relacionada for alterada. Na revisão semestral, use o Search Console para observar queda de impressões, cliques, posição ou consultas que passaram a trazer visitantes sem resposta adequada no artigo.

## Como atualizar sem perder SEO

1. Preserve a URL, o H1 e o tema central quando o assunto continua o mesmo.
2. Atualize exemplos, fontes, capturas, links internos, meta description e trechos tecnicamente superados.
3. Acrescente uma nota “Atualizado em mês/ano” quando a alteração mudar informação relevante. Mantenha a data original de publicação quando a revisão não transformar o artigo em outro conteúdo.
4. Use uma nova data e novo post somente quando o tema, intenção ou público forem realmente diferentes.
5. Não altere datas apenas para aparentar novidade. Isso não substitui uma atualização real.

## RSS

O RSS próprio deve incluir artigos novos e itens atualizados de forma relevante. Não gere uma nova entrada apenas por correção de pontuação ou ajuste de layout. Quando a atualização for material, mantenha o link canônico e atualize a data de modificação no conteúdo e no feed.

## Rotina enxuta

| Frequência | Ação |
|---|---|
| Mensal | Escolher uma pauta, atualizar o calendário e conferir links quebrados nos artigos recentes. |
| Bimestral | Publicar ou finalizar dois artigos autorais, com revisão dos dois sócios antes do envio. |
| Trimestral | Consultar Search Console, identificar dúvidas e links internos faltantes. |
| Semestral | Revisar cada artigo conforme a coluna `next_review` do calendário. |
| Sempre que houver mudança de serviço | Atualizar páginas relacionadas, CTAs e artigos que descrevam aquela entrega. |
